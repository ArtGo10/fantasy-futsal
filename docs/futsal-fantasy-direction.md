# Fantasy Futsal Direction

Этот документ фиксирует направление новой версии приложения: fantasy-лига для конкретной футзальной лиги.

## Референсы

Нишевые futsal fantasy / futsal manager ориентиры:

- PaceCore Fantasy: https://pacecorefantasy.com/
- PaceCore How to Play: https://pacecorefantasy.com/how-to-play/
- HattrickFantasy: https://hattrickfantasy.com/
- FManager futsal manager: https://fmanager.org/
- Futsal Legends на Google Play: https://play.google.com/store/apps/details?id=de.koertge.futsal_legends

Большие fantasy-ориентиры, откуда можно брать механику:

- Fantasy Premier League help: https://fantasy.premierleague.com/help/
- UEFA Champions League Fantasy rules: https://www.uefa.com/uefachampionsleague/news/025f-0fd4b42cc0a7-74498b7df63b-1000--uefa-champions-league-fantasy-football-rules-2023-24/
- UEFA Gaming UCL Fantasy: https://gaming.uefa.com/en/uclfantasy/how-to-play
- LALIGA Fantasy: https://fantasy.laliga.com/

Вывод по рынку: больших официальных futsal fantasy продуктов уровня FPL почти нет. Поэтому базовую механику лучше брать из FPL/UCL Fantasy, а futsal-specific часть проектировать самим.

## Продуктовая идея

Пользователь становится fantasy-manager внутри одной футзальной лиги.

Базовая петля:

1. Создать или вступить в private league.
2. Собрать fantasy-команду из реальных футзальных игроков.
3. Выставить состав на тур/матчдэй до дедлайна.
4. Игроки получают очки за реальные действия в матчах.
5. После тура обновляется таблица managers.
6. Между турами можно делать трансферы.

## MVP механика

Для первой версии лучше сделать проще, чем FPL:

- один общий турнир/сезон;
- private league для наших пользователей;
- squad из 12 футзалистов;
- на каждый тур активны 9 футзалистов: 5 в основе и 4 во второй четверке;
- резерв: 3 футзалиста, которые остаются в команде, но не приносят очки в текущем туре: 1 goalkeeper + 2 universal;
- основа приносит 100% очков, вторая четверка приносит 50%, резерв приносит 0%;
- роли игроков только `goalkeeper` и `universal`;
- бюджет и цена игрока;
- captain x2;
- deadline перед первым матчем тура;
- до первого дедлайна состав можно менять без ограничений;
- после дедлайна состав блокируется до завершения тура и финализации результатов;
- после завершения тура менеджер получает +1 free transfer, максимум можно накопить 5;
- трансфер сверх free transfers получает штраф очками;
- таблица managers;
- история туров;
- ручной или полуавтоматический ввод статистики на старте.

Не брать в MVP:

- chips/wildcards;
- автоматические substitutions;
- сложный live scoring;
- публичные paid contests;
- marketplace/аукцион, если сначала хотим быстрее запуститься.

## Система очков

Текущая версия правил начисления очков: `futsal-fantasy-v1`.

Базовые события матча:

- выход на площадку: +1;
- гол универсала: +4;
- гол вратаря: +8;
- ассист универсала: +2;
- ассист вратаря: +6;
- бонус вратаря за пропущенные мячи: 0 пропущенных = +4, 1 пропущенный = +2, 2 пропущенные = +1;
- если вратарь пропустил больше 2 мячей: -1 за каждый дополнительный пропущенный;
- желтая карточка: -1;
- красная карточка: -3;
- автогол: -2;
- незабитый пенальти: -4;
- отбитый пенальти: +10.

Очки за пропущенные мячи применяются только к вратарям, которые выходили на площадку. Отрицательные очки игрока поддерживаются.

Очки игрока по туру умножаются на роль слота:

- `starter`: x1;
- `bench`: x0.5;
- `reserve`: x0.

Капитан получает x2 к своим очкам. Если капитан не вышел на площадку и набрал 0, капитаном становится вице-капитан.

До первого дедлайна менеджер может без штрафа пересобирать весь состав. После дедлайна текущего тура любые изменения блокируются до финализации результатов тура. Когда админ закрывает тур, всем командам начисляется один бесплатный трансфер, но общий запас free transfers не может быть больше 5. Замена игрока вне бесплатного лимита записывается как paid transfer со штрафом -4 очка. Перестановки внутри состава между основой, второй четверкой и резервом трансфером не считаются.

Fixture profile для тура вычисляется из календаря: `teamsWithDouble` показывает клубы с двумя и более матчами в одном fantasy-туре, `teamsWithBlank` показывает активные клубы без матча в этом туре. Эти данные нужны для подсказок в выборе состава и будущего UI с предупреждениями.

## Новая доменная модель Convex

Оставить:

- `users`

Новые таблицы-кандидаты:

- `fantasyLeagues` - private leagues, season, owner/admin.
- `futsalTeams` - реальные клубы лиги.
- `futsalPlayers` - реальные футзалисты, клуб, роль, цена, статус.
- `futsalMatches` - календарь реальных матчей.
- `futsalPlayerMatchStats` - голы, ассисты, карточки, сейвы, минуты, clean sheet flags.
- `fantasyTeams` - команда пользователя внутри fantasy league.
- `fantasySquadPlayers` - выбранные игроки пользователя.
- `fantasyLineups` - состав на конкретный тур.
- `fantasyGameweeks` - туры/матчдэи, дедлайны, статус.
- `fantasyScores` - рассчитанные очки по туру и total.
- `fantasyTransfers` - история трансферов.
- `fantasyScoringRules` - версия правил начисления очков.

## Первый экран новой версии

Минимальный signed-in shell:

- selected league header: `Fantasy Extra-liga`;
- tabs: `Моя команда`, `Лига`, `Матчи`, `Профиль`;
- публичные экраны доступны без входа;
- админский режим позже: импорт игроков, матчей, статистики.

## Источники данных

Кандидаты:

- официальный сайт Ассоциации футзала Украины `futsal.com.ua`: календарь/таблицы, бомбардиры, ассистенты, карточки, иногда детали матчей;
- Flashscore: календарь, live/final score, таблицы, но без гарантии полноценной player-level статистики;
- 5x5.org.ua и профильные публикации: полезны для сверки, но не как основной автоматический источник;
- ручной admin fallback: нужен на случай, если источник не отдаёт ассисты/карточки по матчу в структурированном виде.

Предпочтительный MVP-пайплайн для Extra-liga: автоматически тянуть календарь и итоговый счёт, отдельно парсить доступные player events из публичных источников лиги, сейчас в первую очередь с `futsal.com.ua`; если событие не распарсилось, показывать админке список матчей, где нужна ручная проверка.

## Идеи на будущее

Пока не реализуем, но фиксируем для следующих этапов:

- добавить обратную связь или поддержку для пользователей внутри приложения;
- сделать экран/компонент с деталями матча: счет, составы, голы, ассисты, карточки, пенальти и другие события;
- возможно, дать менеджерам возможность смотреть составы других игроков;
- где-то выводить подробный отчет по fantasy-очкам игрока за каждый тур: сколько очков он принес и за какие действия.

## Открытые вопросы

- Какая конкретная футзальная лига будет первой?
- Подтвердятся ли ассисты, карточки и отбитые пенальти в стабильном источнике по каждому матчу?
- Нужен draft/auction или обычный FPL-style budget squad?
- Будут ли private leagues только для друзей или в будущем публичные?
- Нужно ли считать очки live или достаточно после завершения матчей?
